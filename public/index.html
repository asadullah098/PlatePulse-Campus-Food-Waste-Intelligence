From plate to pattern

A transparent analytics pipeline you can explain in your viva.

01 / INGEST

Transaction records

120,000 reproducible synthetic meal records, or your own CSV. Each row captures date, venue, meal, served weight and waste weight.

02 / PROCESS

Filter → map → reduce

Validate input, filter the time window, then aggregate by date and venue in a single pass. Raw records remain in server memory.

03 / UNDERSTAND

Signals into decisions

Waste-rate comparison, daily z-score detection, weighted demand forecast and reduction scenarios.

BDA scope: volume, variety of dimensions, aggregation and analytical decision support. This mini project runs on a single Node.js process; it does not claim a distributed Spark/Kafka deployment. See README for the proposed scale-out architecture.

BIG DATA ANALYTICS MINI PROJECT

Meet PlatePulse.

A campus food waste intelligence lab that connects transaction-level data to practical sustainability decisions.

Explore 120,000 synthetic records, import your own CSV, compare venues, detect anomalies and forecast demand. All calculations run on the local Node.js backend.

Data is synthetic unless you import a dataset. Uploaded data is held in memory and resets when the server restarts.
